# Initialize a Company Library Index

Use Init only for an explicitly requested Company Library Index. Require an exact original-material location and
a separate writable index destination; infer neither from topic, tab, folder, or wiki name. For a publishable index,
verify provider identity, index write and governance capability, and current destination audience before discovery. Apply
[Publication](publication.md) using provider-managed wiki permissions by default; verify continuing source inheritance
only when explicitly required by the user or governing policy.

If publication capabilities are unavailable, create and register nothing. The [capability fallback](publication.md#capability-levels)
permits bounded requester-authorized exploration or a transient draft inside the supplied source scope; it does
not establish authorization to generate for the index audience or complete Init. Keep source and destination
requirements explicit, and retain the registry's exact-locator rule for direct-source work.

Perform bounded discovery and representative sampling inside the supplied source scope. This is not ingestion:
do not read every document, create a page per source, copy sources, or claim corpus coverage. For generation intended
for the index audience, exclude content whose evidence audience does not contain that audience or whose explicitly
required protection is unavailable. Use only destination-authorized evidence for that generation. Build the smallest topic-organized progressive-
disclosure map of concepts, entities, systems, processes, policies, projects, decisions, metrics, and source
entry points—not a flat file catalog.

Propose the taxonomy home, nodes, primary-parent tree, compact routing outline, aliases, and the few typed discovery
links that add value beyond taxonomy placement. Each node has one primary tree route; typed links never replace that
route, imply an unsupported relationship, or create a generic graph. Apply only through the [durable change
protocol](change-protocol.md), then register the scoped Company Index profile. Sampling is never a prerequisite for
Personal Wiki Bootstrap.
