# Validate

Validate independently enumerates the visible selected-scope graph within bounds. It is read-only: never edit the
wiki, registry, or original sources. Report broken/inaccessible evidence, version drift, stale summaries, missing
provenance, orphans, duplicates/aliases, contradictions, superseded knowledge, suspicious relationships, permission
leakage, important gaps, missing primary parents, graph-only nodes, and routing-outline/tree drift.

Recheck current evidence access and audience before treating a derived claim as usable. Report static ACL-drift
limits honestly and fail closed for agent-mediated use. Use metadata and bounded reads for drift; offer repairs
through Maintain or Curate, never silently repair them.
