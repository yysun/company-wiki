# Question guide

This is a readable set of recurring questions, not a machine catalog. Each entry gives the shortest
starting point and the evidence the agent should verify.

## People questions

### A-001 — What is the current `vacation-policy`?

Start at the [People guide](people-guide.md), then follow the current HR source link. Answer with the
effective rule, owner, and source date. If versions conflict, show the conflict.

## Customer questions

### A-002 — What is the official definition of an `active-customer`?

Start at the [Customer guide](customer-guide.md), then follow the product source's `defined by` link.
Verify the evaluation date and scope.

### E-003 — How is the `churn-rate` calculated?

Read the customer metric detail and its evidence. State the numerator, denominator, period, and exclusions;
do not infer a trend from a number without those definitions.

## Cross-source questions

### M-004 — Which source wins when two definitions conflict?

Use the [Authoritative lookup guide](authoritative-lookup-guide.md), compare status and dates, and cite
both documents. If the evidence does not establish precedence, report the conflict as unresolved.
