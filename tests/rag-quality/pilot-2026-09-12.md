# Synthetic RAG pilot — September 12, 2026

Twenty of twenty answers passed all 59 answer criteria and the grounding review. This is a development
pilot over short synthetic documents, not a production accuracy estimate.

## Setup

- Model: `gpt-6-astra`; reasoning effort: `high`; CLI: `codex-cli 0.154.0`.
- One fresh, ephemeral, read-only session per question; no answer key in the evaluated context.
- 12 cases use direct source discovery over the existing synthetic fixture corpus.
- 8 cases use the example wiki and seven separate synthetic original documents.
- A deterministic local tool supplies directory listing, regex search, and document reads.
- The same Codex agent authored the questions and reviewed the actual answers against the originals.
  This was not an independent human review.

The [question set](questions.md) and [benchmark guide](README.md) describe the criteria and reproduction steps.

Citation integrity requires an exact quote from an original read during the run and an inline source
reference. It does not establish semantic entailment; the separate grounding review checks the full
answer against original evidence. Required-source recall uses predeclared evidence documents, not an
exhaustive relevance judgment.

The retrieval bounds were two listing/search calls combined, five original-document reads, and 40,000
original-source characters per question. Example navigation required the home first, at most three
additional wiki reads, and no wiki reads after original-source search or reading began.

## Limits and next comparison

One run per question does not measure run-to-run reliability. The small synthetic corpora do not test
large collections, long documents, native provider search, registry selection, initialization, curation,
provider ACLs, or publication. The fixture and example groups use different corpora, so their results
cannot establish the incremental benefit of the wiki.

The next controlled comparison should run the same held-out questions, originals, model, and budgets
with and without wiki routing, followed by independent human calibration of the answer grading.
